- [x] Maven-проект, Java 25, структура пакетов (`engine`, `telegram`, `game`).

### Этап 2. Акторный цикл (один актор)

- [ ] Класс `Actor`: mailbox (MVMap), virtual thread, цикл park/parkUntil/process.
- [ ] Метод `send(actorId, message)`: запись в MVStore + unpark.
- [ ] Сериализация/десериализация сообщений в JSON (records → JSON → records).
- [ ] Тест: один актор, кидаем ему сообщения, он их обрабатывает в правильном порядке.
- [ ] Тест на отложенные сообщения: fireDate в будущем, актор просыпается вовремя.
